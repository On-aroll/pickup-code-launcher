它能帮你做什么

不是又一个"快捷方式合集"，而是把零散通知真正整理成一张可执行的取件表。

批量截图导入

一次最多 30 张，支持长截图分段；也可直接粘贴多条通知文字。

按取件点分组

识别驿站、门店、快递柜名称与地址，自动归组并计数。

识别多种取件码

数字码、字母数字码、横杠货架码都能提取，一条通知多件自动拆开。

先核对再确认

所有识别结果先进"待核对"，可对照原文修改，不擅自删件。

取完划掉

标记已取、误取可恢复；可搜索、可复制本站清单或总表。

保留平台入口

菜鸟 / 淘宝 / 拼多多 / 京东 / 小红书 / 抖音等取件与订单快捷入口都在。

三步用起来

第一次使用也不用注册、不用登录。

第 1 步

导入截图或通知

选"导入多张截图"或"粘贴通知"，保留地点和码，不必只裁数字。

第 2 步

在待核对里确认

核对码、地点、地址与原文，完整项可批量确认。

第 3 步

按地点取件

到一个驿站取完该站所有件，点"已取"，可复制清单分享。

隐私是默认设置

识别在本机完成，不设服务器、不要网络权限；你的取件数据只留在这台手机。

  • 不读取短信、通知栏或账号数据
  • 不申请全相册访问，只读你主动选择的图片
  • 不保存原始截图、不上传任何内容
  • 清单不进入系统云备份，卸载前请自行备份
